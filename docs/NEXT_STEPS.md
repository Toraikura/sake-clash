# 次の評価・改良相談

## 現状

ユーザーは現行版を試遊し「面白い」「直感的」と評価。短いCPU戦で、カードを配置するとすぐ動き、陣地が変わる軽さを保持したい。実装済み仕様はREADME、前回検証はVALIDATION.mdを参照。まず評価・設計を相談し、全部盛りの実装はしない。

## 最優先：iPhone

縦持ち・親指でのタッチ操作が主役。カード選択→盤面タップを基本に、ドラッグは任意。対戦中スクロール不要、指による遮蔽、誤操作、safe area、Safariツールバー、アプリ切替時の停止/再開を考慮。キーボードは補助。実機iPhone Safariは未検証。

## ユーザーの未実装アイデア

1. 文字中心のカードを、盤面に実際に出るユニットと同じ形にする。カード・配置プレビュー・盤面で見た目を統一。
2. 攻撃方向や範囲を矢印などで直感的に示す。前方、四方、反射、移動を区別し、表示が過密にならないようにする。
3. 酒母側とヴィラン側（納豆菌・火落ち菌など）を選べるようにする、またはレベルで敵が登場・解放される仕組み。方式は未決定。菌を普遍的な善悪で説明しない。
4. 敗北時、その相手や状況に関連する香り・化合物への興味を生み、タップで解説へ。ただし菌と化合物を根拠なく一対一対応させない。即再戦を妨げない。
5. 徳利砲などを、火入れアタックのような酒造工程の題材へ。実際の役割とゲーム能力を関連させる。酒母/醪/貯蔵の工程混同や、火入れを酒母戦に入れる抽象化を検討。
6. Color Clash Arenaの直感性・短時間戦・再戦・成長・収集・集客要因を一次資料で分析し応用。人気の規模や因果は未確認。App Store ID6475672172を基準とし、別アプリIDを混ぜない。広告/課金の導入は今回の指示ではない。

## 相談でほしい成果

- 推奨方針一案と、残す/変える点。
- 参考ゲームの確認済み事実、仮説、応用案の対応表。
- iPhone上で何を見てどう触るかがわかる画面・操作案。
- 菌/工程/技候補6〜8個の科学的根拠とゲーム表現。全候補を同時実装しない。
- 陣営選択とレベル解放の比較、敗北→化合物ページの表示文と導線。
- 最小改良、試遊後に追加、保留の3段階と受け入れ条件。
- 少人数の初見試遊と実機iPhone検証の方法。
- 合意後Codexへ渡す具体的な改修依頼。

最初の仮説：カードと盤面の形の統一＋配置前の攻撃方向表示を先に試す。未合意の提案であり、実装済みではない。
